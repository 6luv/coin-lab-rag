### 1. [Medium] src/vectorstore/store.py:100 — 임베딩 실패 전에 기존 문서 청크를 삭제함

- 문제: `index_doc()`가 기존 청크를 삭제한 다음 `add_texts()`로 임베딩을 요청한다. GMS 403·429·연결 실패가 발생하면 해당 문서의 정상 색인이 사라진다. 사용자가 보고한 임베딩 403과 같은 조건에서 발생할 수 있다.

- 수정 방향: 새 임베딩 생성·검증을 먼저 완료하고 안정적인 ID로 upsert한 뒤, 새 ID 집합에 없는 이전 청크만 삭제한다. 실패 시 이전 색인을 유지하는 회귀 테스트를 추가한다.

### 3. [Medium] src/data_prep/docs_store.py:62 — 언어가 다른 동명 문서가 같은 파일을 덮어씀

- 관련 위치: `src/data_prep/docs_store.py:67`.
- 문제: 파일명은 코인 ID와 정제된 제목만 사용한다. `source_type`·`page_id`가 달라도 제목이 같으면 같은 경로가 된다. manifest 역시 제목이 이미 존재하면 새 `doc_id`를 기록하지 않는다.

- 수정 방향: 파일명과 중복 판단에 `(coin_id, doc_id)`를 사용한다. 기존 파일을 이전할 때 manifest와 실제 파일의 ID도 일치시키고, 동명·다국어·정제 제목 충돌 테스트를 추가한다.
