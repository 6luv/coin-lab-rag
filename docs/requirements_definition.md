# 요구사항 정의서 — Coin Lab: 코인 프로젝트 분석 RAG

SSAFY AI 코어 프로젝트 2회차 (RAG 기반 도메인 지식 서비스) · 작성 2026-10-22
기준: `AI코어프로젝트_2회차_요구사항정의서.pdf` (원문 조건·확인 항목 정리본: [`requirements.md`](requirements.md))

## 1. 서비스 개요

가상자산(코인) 프로젝트에 대한 질문에 **수집한 문서만 근거로** 답하고, 답변의 주장마다 근거 번호와 원문 출처(제목·URL·PDF 쪽)를 붙이는 RAG 서비스다.
코인을 고르고 질문하면 관련 위키백과·백서 문서를 그 자리에서 수집·색인한 뒤, LangGraph(retrieve → generate)로 답변을 만든다.

- 항목: 코인 (CoinGecko 시가총액 상위 150개)
- 외부 문서: 한국어·영어 위키백과, 프로젝트 백서(PDF·웹)
- 위험 도메인: 금융(가상자산) → 모든 화면과 답변에 투자 조언이 아니라는 안내

## 2. 도메인 확정 근거 (명세 2.1)

| 조건 | 충족 근거 | 판정 |
|---|---|---|
| 항목 메타데이터 약 100건 이상 | CoinGecko API 로 시가총액 상위 **150개** 수집. 이름·심볼·한글명·순위·카테고리·해시 알고리즘·출시일·발행 플랫폼·설명·시세·7일 가격·로고·백서 링크 | 충족 |
| 항목마다 연결되는 설명 문서 | 위키데이터(P5777) 연결 → 위키백과 검색 → 백서 순으로 확보. 자체 설명 문서가 있는 코인 **102 / 150** (위키백과 47건, 백서 62건). 둘 다 없는 48개는 CoinGecko 설명만 사용 (사용자 결정, D15) | 충족 (문서 보유 코인만으로도 100개 이상) |
| 출처와 이용 조건 기록 | CoinGecko(표기 의무·저장 제한), 위키데이터(CC0), 위키백과(CC BY-SA 4.0), 백서(저작권 프로젝트, 교육용 인용) — [`data_sources.md`](data_sources.md) | 충족 |
| 근거가 필요한 질문 3개 이상 | 아래 2-1, 5개 | 충족 |
| 위험 도메인 여부와 면책 문구 | 금융(가상자산) → 해당. 문구는 2-2 | 충족 |

### 2-1. 근거 없이 답하면 틀리거나 위험한 질문

| # | 질문 | 근거 없이 답할 때의 위험 |
|---|---|---|
| 1 | 이더리움은 언제, 어떤 방식으로 작업증명에서 지분증명으로 바뀌었나? | 날짜·업그레이드 이름을 지어내기 쉽다 |
| 2 | 테더(USDT)의 준비금 구성과 관련해 어떤 논란·제재가 있었나? | 사실과 다른 주장이 널리 퍼져 있다 |
| 3 | 도지코인은 발행량 상한이 있나? | 비트코인과 혼동해 "2,100만 개"로 틀리게 답하기 쉽다 (실제 검증에서 팩트체크가 "사실 아님"으로 판정) |
| 4 | 모네로가 일부 거래소에서 상장 폐지된 이유는? | 규제 맥락이 없으면 추측이 된다 |
| 5 | 카르다노의 개발 단계(바이런·셸리 등)는 무엇인가? | 로드맵 단계 이름을 환각하기 쉽다 |

### 2-2. 면책 안내 문구

> 이 서비스의 답변은 수집된 문서를 요약한 정보이며 투자 조언이 아닙니다. 가상자산은 가격 변동과 원금 손실 위험이 크므로 투자 판단은 본인 책임하에 전문가 상담을 거쳐 결정하세요.

화면 하단 바에 항상, 답변마다 "⚠ 투자 조언이 아닙니다 · 문서 근거 요약"을 표시한다. 답변 프롬프트는 가격 예측·매수·매도 권유를 금지한다.
